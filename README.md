# 🌐 Fatima Aboul | Portfolio Website

A modern, animated developer portfolio built with plain **HTML, CSS, and JavaScript** — no frameworks. Showcases my projects, skills, graphic design work, and learning journey as a Computer Science student.

🔗 **Live Site:** [https://fatima-art12.github.io/FatimaPortfolio/](https://fatima-art12.github.io/FatimaPortfolio/)

---

## ✨ Features

- **Hero Section** — animated typing effect, glowing character illustration
- **About** — orbiting tech-stack icons around a profile photo
- **Skills** — auto-scrolling marquee of tools & technologies
- **Projects** — interactive carousel with image galleries for each project
- **Graphic Designs** — Pinterest-style masonry gallery with a lightbox preview
- **Learning Journey** — animated, scroll-triggered timeline of education & milestones
- **Resume** — inline PDF preview with a one-click download button
- **Contact** — glassmorphism contact form (opens the visitor's email client on submit)
- Fully responsive, dark theme with teal/green accent styling
- Scroll-triggered animations using the Intersection Observer API

---

## 🛠️ Built With

- **HTML5**
- **CSS3** (Flexbox, Grid, CSS Columns, keyframe animations)
- **JavaScript** (Vanilla — no frameworks or libraries)

## 🚀 Running Locally

1. Clone the repo:
   git clone https://github.com/Fatima-art12/FatimaPortfolio.git

2. Open the folder and start a local server (needed for the resume PDF preview to load):
   python -m http.server 5500

3. Open http://localhost:5500 in your browser
